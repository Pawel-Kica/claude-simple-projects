# Official Raycast documentation

- Script Commands manual: https://manual.raycast.com/script-commands the user-facing guide to installing and writing script commands.
- raycast/script-commands GitHub repo: https://github.com/raycast/script-commands templates, the metadata reference, and a community library of examples.
- Developer API docs: https://developers.raycast.com the full Raycast API reference for extensions.
- Script command arguments: https://developers.raycast.com/information/developer-tools/manage-store#arguments how `argument1..3` and the input field JSON work.
- Output modes: https://developers.raycast.com/api-reference the `@raycast.mode` values and how each renders.
- v2 manual and changelog: https://manual.raycast.com what changed in the v2 public beta, check here before assuming a field is gone.
