## Raycast

A Raycast launcher and automation workspace, scripts in `~/claude-projects/raycast/scripts/`, loaded by `/raycast`.

`CLAUDE.md` is the brain (the `# Memories` index plus the most-reached-for facts). `claude-memory/` holds one fact per file. `notes/docs.md` has the official doc links. `sessions.md` is the thin session log. `scripts/` holds the actual script commands.
