# Script metadata: optional fields

- `@raycast.packageName` (group label)
- `@raycast.icon` (emoji or image)
- `@raycast.argument1..3` (input field, value as `$1`; JSON `{ "type": "text"|"dropdown"|"password", "placeholder": "...", "optional": true, "data": [...] }`)
- `@raycast.refreshTime` (e.g. `10s`, `1m`, `1h`, inline mode)
- `@raycast.currentDirectoryPath`
- `@raycast.needsConfirmation` (`true` to prompt)
- `@raycast.author` / `@raycast.authorURL` / `@raycast.description`
