# Raycast version

- Running Raycast v2 (public beta): cross-platform (macOS and Windows), runs alongside v1.
- v2 is beta, so behavior changes between builds. Web-search the official docs (manual.raycast.com, developers.raycast.com) before declaring any metadata field invalid.

Script command vs extension:

- A script command is quick automation in any language. It runs and shows output, no UI. This is the default, reach for it first.
- An extension uses the Raycast API, is TypeScript only, supports rich UI or AI extensions, and is shareable through the store.
