# Scripts built so far

- `search-files.sh` searches a directory for a filename pattern, `fullOutput` mode.
- `clipboard-to-lowercase.sh` lowercases the current clipboard text, `silent` mode with a HUD confirm.
- `display-brightness.sh` sets external display brightness from 10% to 100% via an argument, wraps the CLI from [[display-brightness-cli]], `silent` mode.
